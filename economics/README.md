# Economics model

This directory is Sploot's versioned economic safety input, calculator, and generated decision report.

```bash
pnpm test:economics
pnpm economics -- --write
```

`rates.json` records official list prices and assumptions. `live-usage.json` contains aggregate, redacted readbacks; unavailable billing values are `null` and explained. `workloads.json` defines full-allowance and adversarial scenarios. `policy.json` contains the ratchets and dollar budgets downstream admission controls implement. `REPORT.md` is generated byte-for-byte by `cost-model.mjs`.

Paid tiers are charged at on-demand rates even while current free allowances absorb usage. Fixed web hosting is visible but excluded from the Vision's $25 variable free-subsidy ceiling. Scheduled jobs, inference, storage/renditions/trash, delivery, database work, auth, telemetry, and payments remain explicit.

This model does not activate plans, open enrollment, or substitute for provider hard-cap receipts. Refresh rates and redacted usage on any vendor, plan, limit, or billing-unit change.
