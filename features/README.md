# Sploot feature map

Live stories describe the current Go library, not the retained Next.js predecessor. Source globs name implementation boundaries; changes in a named boundary make its story eligible for the PR walk. The nightly walk covers all stories regardless of changed files.

- [Capture](capture.md) — US-001: browser uploads and device-paired extension capture.
- [Find](find.md) — US-002: local semantic indexing, ranked search, owner isolation.
- [Private library](private-library.md) — US-003: trash, owner export, safe restore.
