## Image Generation Instructions

### Using Gemini CLI (Recommended)

For each screenshot, use:

```bash
# Example for Screenshot 1
gemini-imagegen "A modern browser window showing..." output-file.png \
  --model gemini-3-pro-image-preview \
  --aspect-ratio 16:10 \
  --image-size 2K
```

### Using REST API

```bash
curl -X POST \
  "https://generativelanguage.googleapis.com/v1beta/models/gemini-3-pro-image-preview:generateContent?key=$GEMINI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{"parts": [{"text": "YOUR_PROMPT_HERE"}]}],
    "generationConfig": {
      "responseModalities": ["IMAGE"],
      "imageConfig": {
        "aspectRatio": "16:10",
        "imageSize": "2K"
      }
    }
  }' | jq -r '.candidates[0].content.parts[] | select(.inlineData) | .inlineData.data' | base64 --decode > output.png
```
